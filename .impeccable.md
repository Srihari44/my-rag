## Design Context

### Users
The builder demoing a personal RAG (retrieval-augmented generation) proof-of-concept to colleagues or stakeholders. Viewed on a laptop screen, likely projected or screen-shared during a walkthrough. Sample corpus is IPL cricket documents (Indian Premier League, Chennai Super Kings, Mumbai Indians), so the interface doubles as a live query/answer demo over that data.

### Brand Personality
Sharp, nocturnal, competitive. Think night match under stadium floodlights: confident, high-contrast, a little theatrical, but still a serious technical tool underneath — not a toy. Should read as "built with intent," not a default chatbot template.

### Aesthetic Direction
Dark theme, floodlit-stadium mood: deep charcoal-navy ground with a warm floodlight-amber accent and a cricket-pitch-green secondary accent used sparingly for success/confirmation states. Condensed, sporty display type for headings/scoreboard-style labels (evokes stadium signage), paired with a clean humanist sans for body/chat text. Anti-reference: generic AI chat template (centered card, purple-blue gradient, rounded bubbles everywhere, cyan glow).

### Design Principles
1. Floodlight-on-a-dark-pitch palette — deep charcoal-navy base, amber accent used rarely and deliberately, pitch-green reserved for success/confirmation only.
2. Scoreboard-style condensed display type for structural/label text; body and chat content stay in a legible humanist sans.
3. No default chat-bubble/card monoculture — build the chat and source-citation UI as a distinctive layout, not rounded-rectangle bubbles in a centered card.
4. It's a demo: prioritize a strong first-impression load state and clear visible feedback for upload/query actions (loading, success, error) over exhaustive settings/options.
